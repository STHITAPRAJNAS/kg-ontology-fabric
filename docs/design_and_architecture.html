1. Identity, JWKS & Role Separation

          
    
            
  • Auth Modes: jwt (HS256 ≥ 32-byte secret, or non-blocking to_thread OIDC/JWKS RS256/ES256 requiring iss + aud), api_key, and custom BYOA gateway hooks.
    • 
            
  • Platform Admin vs Tenant Admin: is_platform_admin requires admin role with unscoped/* tenant. Tenant-bound admins get 403 on raw OpenCypher, legacy physical table registration, and cross-tenant DLQ/metrics.
    • 
            
  • Zero Unprivileged LLM Spend: Plain readers get 403 on use_llm_judge=true and synthesize_with_llm=true, trigger 0 LLM calls per query, and receive redacted physical DB names on GET /v1/kbs.
    • 
          

        


        

          
2. Kernel RLS, ABAC & Legacy Table Guard

          
    
            
  • PostgreSQL 16 NOBYPASSRLS: All 7 multi-tenant tables enforce fail-closed RLS via transaction-local SET LOCAL app.current_tenant_id.
    • 
            
  • Cross-Tenant Overwrite & PK Isolation: Tenant-scoped chunk_id + composite PRIMARY KEY (tenant_id, entity_id) on canonical_entity_embeddings block collisions even under DB superuser.
    • 
            
  • Fail-Closed Legacy Tables: validate_legacy_table_access denies pg_catalog, information_schema, and internal tables; requires KG_FABRIC_ALLOWED_LEGACY_TABLES + platform_admin; and blocks re-pointing existing legacy KBs via source_type mutation.
    • 
            
  • Dynamic ABAC Narrowing: Document/KB deletes prune Neo4j/Neptune provenance AND recompute surviving entity/edge acl_groups from remaining chunks.
    • 
          

        


        

          
3. Multi-Replica Concurrency & Fault Tolerance

          
    
            
  • Atomic 1-Job-Per-Tenant: Enforced across concurrent requests and pods via Postgres partial unique index uq_kg_sync_jobs_active_tenant WHERE status IN ('QUEUED','RUNNING') + _job_submit_lock (burst of 5 submits → 1x 202 + 4x 409).
    • 
            
  • Distributed Heartbeat Leases: Active workers pulse heartbeat_at; sibling replicas see live RUNNING jobs without false FAILED flips, while genuinely dead jobs auto-expire after job_stale_timeout_sec.
    • 
            
  • 0ms Immediate Cancel & Safe Retract: Cancelling right after submit immediately transitions to CANCELLED; modified chunks retract old facts only after new extraction succeeds so DLQ failures never drop live facts.
    •
